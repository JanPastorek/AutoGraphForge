906: \begin{prp}\label{prp:Hasse-relations}
907: For any two parameters $\rho$ and $\rho'$ in the Hasse diagram on
908: Fig.~\ref{fig:Hasse},
909: $\rho$ is below $\rho'$ in the diagram if
910: and only if $\rho\le \rho'$.
911: \end{prp}
912: 
913: \begin{proof}
914: Here, we will only argue the `only if' direction of the proof, that is, if
915: $\rho$ is below $\rho'$ in the diagram then $\rho\le \rho'$.
916: The other direction will follow from results in Section~\ref{sec:sharp}.
917: 
918: Clearly, it suffices to verify the statement only for the `covering' pairs $(\rho, \rho')$ in the diagram, that is, pairs such that
919: $\rho$ is immediately below $\rho'$ in the diagram -- the inequalities for all the remaining pairs follow by transitivity.
920: The inequality $\gama\leq \gamawtwo$ can be proved by observing that if
921: $f:V(G)\to\{0,1,2\}$ is a minimum weight weak $2$-dominating function of $G$,
922: then the set $f^{-1}(\{1,2\})$ is a dominating set of $G$
923: of total size $|f^{-1}(1)|+|f^{-1}(2)|\le f(V)= \gamawtwo(G)$.
924: Similarly, if $f:V(G)\to\{0,1,2\}$ is a minimum weight $\{2\}$-dominating function of $G$,
925: then the set $f^{-1}(\{1,2\})$ is a total dominating set of $G$
926: of total size $|f^{-1}(1)|+|f^{-1}(2)|\le f(V)= \gamasettwo(G)$. This implies the inequality
927: $\gamat\le \gamasettwo$. The inequality $\gamma_t\leq{\tilde\gamma}_{w2}$ was
928: proved in \cite{MR3320720} and the inequality ${\tilde\gamma}_{w2}\leq\gamma_R$ in \cite{wx-2010}.
929: 
930: If $f$ is a dominating function of $G$, then $2f$ is a Roman dominating function of $G$ (cf.~\cite{cdhh-2004,MR1991720}). Hence,
931:     for every graph $G$, it holds $\gamaR(G) \le 2\gama(G) = \rgamasettwo(G)$, which establishes the relation
932: $\gamaR\le \rgamasettwo$ in the diagram.
933: 
934: That every rainbow parameter is above its original counterpart
935: is a direct consequence of definitions. Similarly, all other inequalities represented in the diagram $\mathcal H$
936: can be easily derived just by looking at the definitions of parameters.
937: \end{proof}
