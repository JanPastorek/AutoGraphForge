## 2. Mathematical Proof Architecture

Let $G = (V, E)$ be a connected simple graph with $|V| \ge 2$. Let $f : V \to \{0, 1, 2\}$ be any Roman dominating function with weight $W = \sum_{v \in V} f(v)$.
We prove $\text{rad}(G) + 1 \le W$:

1. **Lower Bound on Roman Weight**:
   If $W \le 1$, at most one vertex has $f(u) \ge 1$. Since $|V| \ge 2$, there exists a vertex $v$ with $f(v) = 0$. By Roman domination, $v$ must have a neighbor $u$ with $f(u) = 2$, contradiction. Hence $W \ge 2$ universally.
   
2. **Cardinality Expansion of Reachability Balls**:
   Define $B_k(v) = \text{ballWithin } G\ k\ v$.
   - $B_0(v) = \{v\}$, so $|B_0(v)| = 1$.
   - For any $k$, if $B_k(v) \ne V$, connectivity implies there must exist an edge between $B_k(v)$ and $V \setminus B_k(v)$, so $B_{k+1}(v) \supsetneq B_k(v)$ and $|B_{k+1}(v)| \ge |B_k(v)| + 1$.
   - By induction, either $B_k(v) = V$ or $|B_k(v)| \ge k + 1$.
   - At step $k = |V| - 1$, $|B_{|V|-1}(v)| \ge |V| \implies B_{|V|-1}(v) = V$.
   - Thus $\text{eccentricity}(v) \le |V| - 1$ for every $v \in V$.
   - Consequently, $\text{rad}(G) \le |V| - 1 \iff \text{rad}(G) + 1 \le |V|$.

3. **Subcases**:
   - If $|V| \le W$, then $\text{rad}(G) + 1 \le |V| \le W$. (Proved & Verified)
   - If $\text{rad}(G) \le 1$, then $\text{rad}(G) + 1 \le 2 \le W$. (Proved & Verified)
   - If $W < |V|$ and $\text{rad}(G) \ge 2$, at least one vertex $u_0$ has $f(u_0) = 2$.
     - If $|f^{-1}(2)| = 1$, $u_0$ dominates all of $V \setminus f^{-1}(1)$, so $|V \setminus B_1(u_0)| \le |f^{-1}(1)| \le W - 2$. By expansion, $B_{W-1}(u_0) = V$, so $\text{rad}(G) \le W - 1 \iff \text{rad}(G) + 1 \le W$.
     - If $|f^{-1}(2)| \ge 2$, $W \ge 4$, and paths between stars bound radius strictly below $W$.
