$$\forall v \in V, \exists u \in s, G.\mathrm{Adj}(v, u)$$

1. **No total dominating set can be empty ($|s| \ge 1$):**
   If $s = \emptyset$, no vertex has a neighbor in $s$. Since $G$ is nontrivial ($2 \le |V|$), $V$ is nonempty, yielding an immediate contradiction.
2. **No total dominating set can be a singleton ($|s| \ge 2$):**
   If $s = \{x\}$, every vertex in $V$ must be adjacent to an element in $s$. In particular, for $v = x$, there must exist $u \in \{x\}$ with $G.\mathrm{Adj}(x, u)$. Because $u = x$, this requires $G.\mathrm{Adj}(x, x)$, which contradicts the irreflexivity of simple graphs.

Thus, **every** total dominating set in any loopless graph must have at least 2 vertices. Because $\text{HasTotalDominationNumber}(G)$ guarantees that the family of total dominating sets is non-empty, the minimum cardinality $\gamma_t(G) = \text{minCard}(\text{IsTotalDominatingSet } G)$ is at least 2.
