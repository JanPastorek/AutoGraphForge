$$\text{IsNontrivialClass}(G) \implies \text{HasEdgeCover}(G) \implies \text{order}(G) \le 2 \cdot \text{edgeCoverNumber}(G)$$

### Key Mathematical Idea
1. **Edge Cover Vertex Bound**:
   Any edge cover $s \subseteq E(G)$ satisfies $V \subseteq \bigcup_{e \in s} e$. Since each undirected edge has $|e| \le 2$ endpoints, subadditivity of cardinality gives:
   $$|V| \le \left|\bigcup_{e \in s} e\right| \le 2 \cdot |s|$$
2. **Analysis of `minUpTo`**:
   `GraphCalc.edgeCoverNumber G` is computed via `GraphCalc.minUpTo (|V|) P`, which finds the minimal size $k \le |V|$ of an edge cover.
   - If an edge cover exists at size $k \le |V|$, then $|V| \le 2k = 2 \cdot \text{edgeCoverNumber}(G)$.
   - If no cover of size $\le |V|$ exists, `minUpTo` defaults to $|V|$, where $|V| \le 2|V|$ holds trivially.
